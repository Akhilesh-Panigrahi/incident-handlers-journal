# Incident Response Notes

## Incident Lifecycle

The journal exercises demonstrated several stages of incident response:

```
Detection and Analysis
        ↓
Containment
        ↓
Eradication
        ↓
Recovery
```

---

## Detection and Analysis

The journal included investigations involving:

- Ransomware detection
- Packet capture analysis
- Suspicious file hash investigation
- SOC alert investigation

## Containment

The ransomware scenario documented immediate containment through deactivation of the organization's computer systems.

## Eradication and Recovery

The organization collaborated with external organizations to eliminate the ransomware and restore affected systems.

---

## Security Tools

| Tool | Investigation Use |
|---|---|
| Wireshark | Packet capture analysis |
| tcpdump | Command-line network traffic capture and analysis |
| VirusTotal | Suspicious file/hash investigation |

---

## Key Lessons

The exercises demonstrated the importance of:

- Structured incident documentation
- Network traffic analysis
- Indicator investigation
- Alert validation
- Containment
- Eradication
- Recovery
- Security awareness

---

## Analyst Perspective

Incident response requires both technical investigation and disciplined documentation. The exercises helped connect security tools with the broader incident response lifecycle.
