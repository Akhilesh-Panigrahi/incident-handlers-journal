# tcpdump Network Analysis

## Exercise Overview

This exercise involved capturing and analyzing network traffic using tcpdump.

## Tool

**tcpdump**

tcpdump is a command-line network protocol analyzer that can be used to capture, filter, and analyze network traffic.

## Objective

The objective was to capture network traffic and gain practical experience using a command-line network analysis tool.

## Challenges

The command-line interface presented a challenge because of my limited experience with tcpdump.

Incorrect commands resulted in minor setbacks. By reviewing the instructions and repeating the necessary steps, I successfully completed the activity and captured network traffic.

## Security Relevance

Command-line network analysis provides security analysts with another method for capturing and investigating network traffic.

## Key Takeaway

The exercise reinforced the importance of carefully reading command syntax and methodically troubleshooting incorrect results when working with security tools.
