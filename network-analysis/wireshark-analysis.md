# Wireshark Network Analysis

## Exercise Overview

This exercise involved analyzing a packet capture file using Wireshark.

## Tool

**Wireshark**

Wireshark is a graphical network protocol analyzer used to capture and analyze network traffic.

## Objective

The objective was to examine a packet capture and develop familiarity with network traffic analysis.

## Experience

This was my first experience using Wireshark.

The interface initially presented a learning challenge, but working through the exercise provided a better understanding of how network protocol analysis can support cybersecurity investigations.

## Security Relevance

Network traffic analysis can help security analysts investigate suspicious communications and identify activity that may require additional investigation.

## Key Takeaway

The exercise introduced practical network analysis using a graphical protocol analyzer and increased my familiarity with examining captured network traffic.
