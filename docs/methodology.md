# Investigation Methodology

## Overview

The exercises in this project followed a structured investigation approach.

## 1. Identify the Security Event

Determine what triggered the investigation, such as:

- Ransomware detection
- Suspicious file detection
- Network traffic requiring analysis

## 2. Establish Context

Document the available information using the 5 W's:

- Who
- What
- Where
- When
- Why

## 3. Analyze Evidence

Use the appropriate security tool for the investigation:

- Wireshark for packet capture analysis
- tcpdump for command-line traffic capture
- VirusTotal for suspicious file/hash investigation

## 4. Determine Security Significance

Evaluate whether the available information indicates suspicious or malicious activity.

## 5. Determine Response

Where applicable, identify containment, eradication, and recovery actions.

## 6. Document Findings

Record observations, investigative actions, challenges, and lessons learned.

## Limitations

These exercises were educational scenarios. The journal does not contain complete production logs, endpoint telemetry, full packet-capture datasets, or a complete enterprise incident-response investigation.
